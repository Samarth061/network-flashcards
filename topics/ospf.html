Abbreviations

AbbreviationFull formBrief meaning
OSPFOpen Shortest Path FirstLink-state routing protocol (standardized)
SPFShortest Path FirstDijkstra's algorithm used by OSPF to compute best paths
LSALink State AdvertisementPacket used to share topology info between routers
LSDBLink State DatabaseThe topology table — identical for all routers in an area
RIDRouter IDUnique 32-bit identifier for each OSPF router
DRDesignated RouterElected router on multi-access networks to reduce LSA flooding
BDRBackup Designated RouterStandby DR; takes over if the DR fails
DBDDatabase DescriptorSummary of a router's topology DB, exchanged during adjacency formation
ABRArea Border RouterRouter with interfaces in 2+ OSPF areas
ASBRAutonomous System Border RouterRouter connecting OSPF to an external AS or redistributing another protocol
ASAutonomous SystemA network under a single administrative domain
NBMANon-Broadcast Multi-AccessNetwork type where multiple routers share a link but broadcasts aren't supported (e.g. Frame Relay)
P2PPoint-to-PointNetwork type with exactly two routers directly connected
P2MPPoint-to-MultipointNetwork type where one interface connects to multiple destinations, each treated as P2P
VLSMVariable Length Subnet MaskAbility to use different prefix lengths; OSPF supports this as a classless protocol
NSSANot So Stubby AreaStub-like area that also allows an internal ASBR using Type 7 LSAs
TNSSATotally Not So Stubby AreaNSSA variant that also blocks Type 3 (inter-area) LSAs
MOSPFMulticast OSPFExtension of OSPF for multicast routing; uses Type 6 LSAs
E1External Type 1External route metric = external cost + internal cost to ASBR
E2External Type 2External route metric = external cost only (default)
PIDProcess IDLocal identifier for an OSPF process; unique per router, not domain-wide
PPPPoint-to-Point ProtocolData link protocol commonly used on serial/T1 links
HDLCHigh-Level Data Link ControlDefault encapsulation on Cisco serial interfaces
ATMAsynchronous Transfer ModeCell-based networking technology; treated as broadcast multi-access in OSPF
