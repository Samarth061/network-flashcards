Problem 1

Longest Substring Without Repeating Characters

Medium

Given a string s, find the length of the longest substring without repeating characters.

Input: s = "abcabcbb" → Output: 3 ("abc") Input: s = "bbbbb" → Output: 1 Input: s = "pwwkew" → Output: 3 ("wke")
Clarify First
  • What characters? ASCII only, or Unicode?
  • Return length only, or the actual substring?
  • Empty string input → return 0?
  • Single character → return 1?
💡 Hint
Use a sliding window [left..right]. Keep a dict mapping char → last seen index. When you see a duplicate inside the window, jump left past it.
✅ Solution + Complexity 
def length_of_longest_substring(s: str) -> int:
    last_seen = {}
    left = 0
    best = 0
    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        best = max(best, right - left + 1)
    return best

# Trace s="abba":
# r=0 a: window=[a] best=1
# r=1 b: window=[ab] best=2
# r=2 b: b seen at 1 >= left=0 → left=2, window=[b] best=2
# r=3 a: a seen at 0 < left=2 → no shrink, window=[ba] best=2
assert length_of_longest_substring("abcabcbb") == 3
assert length_of_longest_substring("bbbbb") == 1
assert length_of_longest_substring("abba") == 2
Time: O(n)    Space: O(min(n, alphabet))
What to say: "Window invariant: all chars in [left..right] are unique. The >= left check prevents shrinking left backward when we see a stale entry."
Problem 2

Top-K Most Frequent Elements

Medium

Given an array of log severity strings, return the k most frequent ones in descending order of frequency.

Input: logs = ["ERROR","WARN","ERROR","INFO","ERROR","WARN"], k = 2 Output: ["ERROR", "WARN"] (3 and 2 occurrences)
Clarify First
  • Return just names, or (name, count) pairs?
  • Ties: any order acceptable?
  • Is k guaranteed ≤ distinct elements?
  • Case sensitive?
💡 Hint
Count with a dict or Counter. Then use heapq.nlargest(k, freq, key=freq.get) — O(n log k) vs sort O(n log n).
✅ Solution + Complexity 
import heapq
from collections import Counter
from typing import List

def top_k_frequent(logs: List[str], k: int) -> List[str]:
    freq = Counter(logs)
    # heapq.nlargest: O(n log k) — better than sort when k << n
    return heapq.nlargest(k, freq, key=freq.get)

# Also works: return [item for item, _ in Counter(logs).most_common(k)]

assert top_k_frequent(["ERROR","WARN","ERROR","INFO","ERROR","WARN"], 2) == ["ERROR","WARN"]
Time: O(n log k)    Space: O(n)
What to say: "Counter is a dict subclass — mention the manual version: freq[x] = freq.get(x,0)+1. heapq.nlargest beats sorting when k is small."
Problem 3

Merge Overlapping Intervals

Medium

Given a list of maintenance windows [start, end], merge all overlapping windows and return the result.

Input: [[1,3],[2,6],[8,10],[15,18],[9,12]] Output: [[1,6],[8,12],[15,18]]
Clarify First
  • Is input already sorted?
  • Are intervals inclusive on both ends?
  • What if the list is empty?
  • What if there is only one interval?
💡 Hint
Sort by start time first. Then iterate: if current start ≤ last merged end, extend the last merged interval. Otherwise append new.
✅ Solution + Complexity 
from typing import List

def merge(intervals: List[List[int]]) -> List[List[int]]:
    if not intervals:
        return []
    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:           # overlapping
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged

assert merge([[1,3],[2,6],[8,10],[15,18],[9,12]]) == [[1,6],[8,12],[15,18]]
assert merge([[1,4],[4,5]]) == [[1,5]]  # touching intervals merge
Time: O(n log n)    Space: O(n)
What to say: "Sort first — O(n log n) total. Then one linear sweep. Key edge case: touching intervals [1,4],[4,5] → should merge to [1,5] because start ≤ prev_end (4 ≤ 4)."
Problem 4

Valid Parentheses

Easy

Given a string containing '(', ')', '{', '}', '[', ']', determine if the brackets are valid (correctly matched and nested).

"([])" → True "([)]" → False "{[]}" → True "(" → False "" → True
Clarify First
  • Other characters: ignored or invalid?
  • Empty string → True?
  • Uppercase letters mixed in?
  • Return bool only?
💡 Hint
Use a stack. Push open brackets. On close bracket, check top of stack matches.
✅ Solution + Complexity 
def is_valid(s: str) -> bool:
    stack = []
    closing = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in ')]}':
            if not stack or stack[-1] != closing[ch]:
                return False
            stack.pop()
    return len(stack) == 0

assert is_valid("([])")  is True
assert is_valid("([)]")  is False
assert is_valid("")      is True
assert is_valid("(")     is False
Time: O(n)    Space: O(n)
What to say: "Three edge cases before coding: empty string → True; opener with no closer → stack non-empty at end → False; closer with empty stack → False."
Problem 5

BFS Shortest Path in Network Graph

Medium

Given a network topology as an adjacency list and two nodes, return the minimum number of hops between them, or -1 if unreachable.

graph = { "core": ["dist1", "dist2"], "dist1": ["access1"], "dist2": ["access2"], "access1": [], "access2": [] } shortest_path("core", "access1") → 2
Clarify First
  • Directed or undirected graph?
  • Return hop count or the actual path?
  • Are edge weights all equal (unweighted)?
  • Can start == end?
💡 Hint
BFS guarantees shortest path in unweighted graphs. Use a deque for O(1) popleft. Track visited set to avoid cycles.
✅ Solution + Complexity 
from collections import deque
from typing import Dict, List

def shortest_hops(graph: Dict[str, List[str]], start: str, end: str) -> int:
    if start == end:
        return 0
    visited = {start}
    queue   = deque([(start, 0)])
    while queue:
        node, hops = queue.popleft()
        for neighbor in graph.get(node, []):
            if neighbor == end:
                return hops + 1
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, hops + 1))
    return -1  # unreachable

topo = {"core":["dist1","dist2"],"dist1":["access1"],"dist2":["access2"],"access1":[],"access2":[]}
assert shortest_hops(topo, "core", "access1") == 2
assert shortest_hops(topo, "core", "core") == 0
assert shortest_hops(topo, "access1", "access2") == -1
Time: O(V+E)    Space: O(V)
What to say: "BFS explores level by level — the first time you reach end is the shortest path. Initialize visited with start before the loop. deque is O(1) popleft vs list's O(n)."
Problem 6

Parse Key-Value Config String

Medium

Parse a string of space-separated key=value pairs into a dict. Values may be quoted strings containing spaces. Handle missing values gracefully.

Input: 'host=10.0.0.1 port=22 description="my router"' Output: {"host": "10.0.0.1", "port": "22", "description": "my router"}
Clarify First
  • Can values contain = signs?
  • Are quoted values always double-quoted?
  • What if a key appears twice?
  • Unquoted values — can they contain special chars?
💡 Hint
Use shlex.split() to handle quoted strings, then split each token on the first '=' using str.partition('=').
✅ Solution + Complexity 
import shlex
from typing import Dict

def parse_kv_config(s: str) -> Dict[str, str]:
    """
    Parse 'key=value key2="quoted value"' into a dict.
    Uses shlex.split to handle quoted values with spaces.
    """
    result = {}
    try:
        tokens = shlex.split(s)
    except ValueError:
        # Fallback: simple split on whitespace if shlex fails
        tokens = s.split()

    for token in tokens:
        if '=' in token:
            key, _, value = token.partition('=')
            key = key.strip()
            if key:
                result[key] = value
        # Silently skip tokens without '=' (malformed)
    return result

s = 'host=10.0.0.1 port=22 description="my router" timeout=30'
result = parse_kv_config(s)
assert result['host'] == '10.0.0.1'
assert result['description'] == 'my router'
assert result['port'] == '22'
Time: O(n)    Space: O(n)
What to say: "shlex.split handles quoted strings correctly — it's stdlib. str.partition('=') splits on the FIRST = only, so values containing = are preserved. Edge case: key= → empty string value, which is fine."
Problem 7

LRU Cache

Medium

Implement a Least Recently Used (LRU) cache with O(1) get and put operations. When capacity is reached, evict the least recently used item.

LRUCache(2) put(1, 1); put(2, 2) get(1) → 1 put(3, 3) ← evicts key 2 get(2) → -1 ← was evicted
Clarify First
  • get() on missing key returns -1?
  • Is capacity always positive?
  • put() on existing key updates value and marks as recently used?
  • Thread safety needed?
💡 Hint
OrderedDict maintains insertion order AND supports move_to_end(key). Most recently used = end; LRU = front.
✅ Solution + Complexity 
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cap   = capacity
        self.cache = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)   # mark as recently used
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.cap:
            self.cache.popitem(last=False)  # evict LRU (front)

c = LRUCache(2)
c.put(1, 1); c.put(2, 2)
assert c.get(1) == 1    # moves 1 to end; order: [2, 1]
c.put(3, 3)             # evicts 2 (front)
assert c.get(2) == -1
Time: O(1) per get/put    Space: O(capacity)
What to say: "OrderedDict.move_to_end(key) is O(1) — that's the key insight. popitem(last=False) removes from the front (LRU). If they ask for the doubly-linked list version, that's the follow-up."
Problem 8

Detect Cycle in Directed Graph

Medium

Given a directed graph as an adjacency list, return True if there is a cycle, False otherwise.

{"A":["B"], "B":["C"], "C":["A"]} → True (A→B→C→A) {"A":["B"], "B":["C"], "C":[]} → False {"A":["A"]} → True (self-loop)
Clarify First
  • Self-loops count as cycles?
  • Disconnected graph — check all components?
  • Directed or undirected? (affects algorithm choice)
  • Return which nodes form the cycle, or just bool?
💡 Hint
DFS with three colors: WHITE (unvisited), GRAY (on current stack), BLACK (done). If you reach a GRAY node, that's a back-edge = cycle.
✅ Solution + Complexity 
from typing import Dict, List

def has_cycle(graph: Dict[str, List[str]]) -> bool:
    WHITE, GRAY, BLACK = 0, 1, 2
    color = {n: WHITE for n in graph}

    def dfs(node):
        color[node] = GRAY
        for neighbor in graph.get(node, []):
            if neighbor not in color:
                color[neighbor] = WHITE
            if color[neighbor] == GRAY:  # back-edge
                return True
            if color[neighbor] == WHITE and dfs(neighbor):
                return True
        color[node] = BLACK
        return False

    return any(dfs(n) for n in list(graph) if color.get(n) == WHITE)

assert has_cycle({"A":["B"],"B":["C"],"C":["A"]}) is True
assert has_cycle({"A":["B"],"B":["C"],"C":[]})    is False
assert has_cycle({"A":["A"]})                      is True
Time: O(V+E)    Space: O(V)
What to say: "Why three colors and not two? In a directed graph, reaching a visited node via a different path is NOT a cycle. GRAY means 'currently on the recursion stack' — that's the back-edge condition. BLACK means fully explored."
Problem 9

Running Median of Latency Stream

Medium

Design a data structure that supports adding integers and querying the median at any point.

add(5) → median = 5 add(15) → median = 10.0 add(1) → median = 5 add(3) → median = 4.0 add(8) → median = 5
Clarify First
  • Integer or float inputs?
  • Can the median be a float (average of two middle values)?
  • How many elements expected — do we need streaming efficiency?
  • add() + median() interface?
💡 Hint
Two heaps: a max-heap for the lower half, min-heap for the upper half. Keep them balanced (sizes differ by at most 1).
✅ Solution + Complexity 
import heapq

class MedianFinder:
    def __init__(self):
        self.lo = []  # max-heap (negate for Python)
        self.hi = []  # min-heap

    def add(self, num: float) -> None:
        heapq.heappush(self.lo, -num)
        # Ensure lo's max <= hi's min
        if self.hi and -self.lo[0] > self.hi[0]:
            heapq.heappush(self.hi, -heapq.heappop(self.lo))
        # Balance sizes: lo can be 1 larger than hi
        if len(self.lo) > len(self.hi) + 1:
            heapq.heappush(self.hi, -heapq.heappop(self.lo))
        elif len(self.hi) > len(self.lo):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def median(self) -> float:
        if len(self.lo) == len(self.hi):
            return (-self.lo[0] + self.hi[0]) / 2.0
        return float(-self.lo[0])

mf = MedianFinder()
for x in [5, 15, 1, 3, 8]:
    mf.add(x)
assert mf.median() == 5.0
Time: O(log n) per add, O(1) median    Space: O(n)
What to say: "Lower half = max-heap (negate for Python's min-heap). Upper half = min-heap. Invariant: max(lo) ≤ min(hi) and |len(lo) - len(hi)| ≤ 1. Equal sizes → median = average of both tops."
Problem 10

Longest Common Prefix of Hostnames

Easy

Given a list of hostnames, find the longest common prefix string.

["flower", "flow", "flight"] → "fl" ["dog", "racecar", "car"] → "" ["abc"] → "abc"
Clarify First
  • Empty list → return ""?
  • Single element → return that element?
  • Case-sensitive?
  • All same string → return that string?
💡 Hint
Compare character by character using zip(*strs) which zips all strings together column by column. zip stops at the shortest string automatically.
✅ Solution + Complexity 
from typing import List

def longest_common_prefix(strs: List[str]) -> str:
    if not strs:
        return ""
    result = []
    for chars in zip(*strs):  # zip stops at shortest string
        if len(set(chars)) == 1:
            result.append(chars[0])
        else:
            break
    return ''.join(result)

# Alternative: sort + compare first/last
def longest_common_prefix_v2(strs: List[str]) -> str:
    if not strs:
        return ""
    strs.sort()
    a, b = strs[0], strs[-1]  # min and max after sort
    i = 0
    while i < len(a) and i < len(b) and a[i] == b[i]:
        i += 1
    return a[:i]

assert longest_common_prefix(["flower","flow","flight"]) == "fl"
assert longest_common_prefix(["dog","racecar","car"]) == ""
assert longest_common_prefix(["abc"]) == "abc"
Time: O(n·m) where m = shortest string length    Space: O(m)
What to say: "zip(*strs) is Pythonic — it transposes the list of strings into columns. The sort-then-compare approach is clean too: min and max after sort differ only after the shared prefix."
Problem 11

Two Sum (Port Pairs)

Easy

Given a list of port numbers and a target sum, return indices of the two ports that add up to target. Each input has exactly one solution.

ports = [80, 443, 22, 8080], target = 465 Output: [1, 2] (443 + 22 = 465)
Clarify First
  • Return indices or values?
  • Exactly one solution guaranteed?
  • Same element used twice allowed?
  • Sorted or unsorted input?
💡 Hint
Single-pass hashmap: for each number, check if target - num is already in the map. If yes, done. If not, store num → index.
✅ Solution + Complexity 
from typing import List

def two_sum(nums: List[int], target: int) -> List[int]:
    seen = {}  # value → index
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []  # no solution (won't happen per guarantee)

assert two_sum([80, 443, 22, 8080], 465) == [1, 2]
assert two_sum([2, 7, 11, 15], 9) == [0, 1]
Time: O(n)    Space: O(n)
What to say: "One-pass: store num → index as we go. When we see a number, check if its complement was already seen. Avoids the naive O(n²) double loop."
Problem 12

Group Hostnames by Pattern (Anagram Groups)

Medium

Given a list of hostnames, group those that are anagrams of each other (same characters in different order).

Input: ["eat","tea","tan","ate","nat","bat"] Output: [["bat"], ["nat","tan"], ["ate","eat","tea"]]
Clarify First
  • Case-sensitive?
  • Return any order within groups?
  • Return list of lists or dict?
  • Empty list input?
💡 Hint
Key = sorted characters of the string. Group by this key using a defaultdict.
✅ Solution + Complexity 
from collections import defaultdict
from typing import List

def group_anagrams(strs: List[str]) -> List[List[str]]:
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))  # canonical form
        groups[key].append(s)
    return list(groups.values())

result = group_anagrams(["eat","tea","tan","ate","nat","bat"])
# Sort for deterministic comparison
result_sets = sorted([sorted(g) for g in result])
assert result_sets == [["bat"], ["ate","eat","tea"], ["nat","tan"]]
Time: O(n · k log k) where k = max string length    Space: O(n·k)
What to say: "The canonical key is tuple(sorted(s)) — all anagrams share the same key. defaultdict(list) groups them automatically. Network use case: normalizing hostname variants, grouping BGP prefixes by prefix length."

IPv4 ↔ Integer Conversion

Easy

Write functions to convert an IPv4 dotted-decimal string to a 32-bit integer and back.

ipv4_to_int("192.168.1.1") → 3232235777 int_to_ipv4(3232235777) → "192.168.1.1"
Clarify First
  • Handle leading zeros in octets?
  • Validate range 0-255 per octet?
  • Return -1 on error or raise?
  • IPv6 needed?
💡 Hint
Process each octet, shift left 8 bits, OR with octet value. Reverse for int → string.
✅ Solution + Complexity 
def ipv4_to_int(ip: str) -> int:
    parts = ip.split('.')
    if len(parts) != 4:
        raise ValueError(f"Invalid IP: {ip!r}")
    result = 0
    for p in parts:
        if not p.isdigit():
            raise ValueError(f"Non-numeric octet: {p!r}")
        v = int(p)
        if v < 0 or v > 255:
            raise ValueError(f"Octet out of range: {v}")
        result = (result << 8) | v
    return result

def int_to_ipv4(n: int) -> str:
    return '.'.join(str((n >> shift) & 0xFF) for shift in (24, 16, 8, 0))

assert ipv4_to_int("192.168.1.1") == 3232235777
assert int_to_ipv4(3232235777) == "192.168.1.1"
assert int_to_ipv4(ipv4_to_int("10.0.0.1")) == "10.0.0.1"
assert ipv4_to_int("0.0.0.0") == 0
assert ipv4_to_int("255.255.255.255") == 0xFFFFFFFF
Time: O(1)    Space: O(1)
What to say: "Each octet is 8 bits. Shift current result left 8, OR with octet. For reverse: right-shift and mask with 0xFF to extract each 8-bit group. Always validate octets — out-of-range values are a common interview trap."

CIDR Membership Check

Easy

Given an IPv4 address and a CIDR block, determine if the IP is within the network.

ip_in_cidr("10.1.2.3", "10.0.0.0/8") → True ip_in_cidr("11.0.0.1", "10.0.0.0/8") → False ip_in_cidr("10.0.0.0", "10.0.0.0/32") → True ip_in_cidr("10.0.0.1", "10.0.0.0/32") → False
Clarify First
  • Is IP guaranteed valid?
  • Prefix length 0 → all IPs match (default route)?
  • Prefix length 32 → only exact host match?
  • Use stdlib ipaddress module or raw bit ops?
💡 Hint
(ip_int & mask) == network_int. Mask = (0xFFFFFFFF << (32-prefix)) & 0xFFFFFFFF.
✅ Solution + Complexity 
def ipv4_to_int(ip):
    r = 0
    for p in ip.split('.'): r = (r << 8) | int(p)
    return r

def ip_in_cidr(ip: str, cidr: str) -> bool:
    ip_str, prefix_str = cidr.split('/')
    prefix = int(prefix_str)
    mask = (0xFFFFFFFF << (32 - prefix)) & 0xFFFFFFFF if prefix > 0 else 0
    ip_int  = ipv4_to_int(ip)
    net_int = ipv4_to_int(ip_str) & mask
    return (ip_int & mask) == net_int

# Alternative with stdlib:
import ipaddress
def ip_in_cidr_stdlib(ip, cidr):
    return ipaddress.ip_address(ip) in ipaddress.ip_network(cidr, strict=False)

assert ip_in_cidr("10.1.2.3", "10.0.0.0/8")  is True
assert ip_in_cidr("11.0.0.1", "10.0.0.0/8")  is False
assert ip_in_cidr("10.0.0.0", "10.0.0.0/32") is True
assert ip_in_cidr("10.0.0.1", "10.0.0.0/32") is False
Time: O(1)    Space: O(1)
What to say: "Always network the network address against the mask before comparing. Edge case: prefix=0 means mask=0, so all IPs match (default route 0.0.0.0/0). prefix=32 is an exact host match."
NA-3

Longest Prefix Match

Medium

Given an IP address and a list of CIDR prefixes (routing table), return the most specific matching prefix (longest prefix length), or None if no match.

cidrs = ["0.0.0.0/0", "10.0.0.0/8", "10.1.0.0/16", "10.1.2.0/24"] lpm("10.1.2.99", cidrs) → "10.1.2.0/24" lpm("10.1.5.1", cidrs) → "10.1.0.0/16" lpm("172.16.0.1",cidrs) → "0.0.0.0/0"
Clarify First
  • Can the list be empty?
  • IP guaranteed valid?
  • Return the CIDR string or just prefix length?
  • No match → return None or default route?
  • Is 0.0.0.0/0 always in the list?
💡 Hint
Linear scan all CIDRs. For each matching CIDR, track the one with highest prefix length. O(n) — mention trie for O(32) lookup if asked.
✅ Solution + Complexity 
from typing import List, Optional

def ipv4_to_int(ip):
    r = 0
    for p in ip.split('.'): r = (r << 8) | int(p)
    return r

def parse_cidr(cidr):
    ip_str, plen = cidr.split('/')
    prefix = int(plen)
    mask = (0xFFFFFFFF << (32 - prefix)) & 0xFFFFFFFF if prefix > 0 else 0
    return ipv4_to_int(ip_str) & mask, prefix

def longest_prefix_match(ip: str, cidrs: List[str]) -> Optional[str]:
    ip_int = ipv4_to_int(ip)
    best, best_len = None, -1
    for cidr in cidrs:
        net, plen = parse_cidr(cidr)
        mask = (0xFFFFFFFF << (32 - plen)) & 0xFFFFFFFF if plen > 0 else 0
        if (ip_int & mask) == net and plen > best_len:
            best, best_len = cidr, plen
    return best

cidrs = ["0.0.0.0/0","10.0.0.0/8","10.1.0.0/16","10.1.2.0/24"]
assert longest_prefix_match("10.1.2.99", cidrs) == "10.1.2.0/24"
assert longest_prefix_match("10.1.5.1",  cidrs) == "10.1.0.0/16"
assert longest_prefix_match("172.16.0.1",cidrs) == "0.0.0.0/0"
Time: O(n)    Space: O(1)    Follow-up: Trie = O(32) lookup
What to say: "Linear scan is fine for small routing tables. For large tables (millions of prefixes in a real router), use a prefix trie (Patricia tree / radix tree) for O(prefix_length) = O(32) lookup. Always mention this as a follow-up."

Detect CIDR Overlap

Medium

Given two CIDR blocks, determine if they share any IP addresses.

def ipv4_to_int(ip):
    r = 0
    for p in ip.split('.'): r = (r << 8) | int(p)
    return r

def cidr_range(cidr):
    """Returns (first_ip_int, last_ip_int) for a CIDR block."""
    ip_str, plen = cidr.split('/')
    prefix = int(plen)
    mask  = (0xFFFFFFFF << (32 - prefix)) & 0xFFFFFFFF if prefix > 0 else 0
    start = ipv4_to_int(ip_str) & mask
    end   = start + (1 << (32 - prefix)) - 1
    return start, end

def cidrs_overlap(cidr_a: str, cidr_b: str) -> bool:
    a_start, a_end = cidr_range(cidr_a)
    b_start, b_end = cidr_range(cidr_b)
    return max(a_start, b_start) <= min(a_end, b_end)

assert cidrs_overlap("10.0.0.0/8",   "10.1.0.0/16")     is True
assert cidrs_overlap("10.0.0.0/8",   "11.0.0.0/8")      is False
assert cidrs_overlap("192.168.0.0/24","192.168.0.128/25") is True
assert cidrs_overlap("10.0.0.0/8",   "10.0.0.0/8")      is True

What to say: "Reduce to range intersection: two ranges overlap iff max(starts) ≤ min(ends). End of a CIDR: start + 2^(32-prefix) - 1. Edge cases: identical CIDRs and one completely inside another both correctly return True."

Parse Ping Output → JSON

Medium

Given raw ping output text, extract packet statistics and RTT values into a structured dict.

Input: Linux ping stdout (4 packets) Output: { "transmitted": 4, "received": 4, "loss_pct": 0.0, "rtt_avg_ms": 14.0, "rtt_min_ms": 12.9, "rtt_max_ms": 15.1 }

  • What if ping timed out completely (no RTT line)?
  • Return None or 0 on missing fields?
  • Individual per-packet RTTs needed?
💡 Hint
Compile three regex patterns: RTT per line (time=X.X ms), stats line (transmitted/received), RTT summary line (min/avg/max).
✅ Solution + Complexity 
import re
from typing import Dict, Any

_RTT_RE   = re.compile(r'time=(\d+(?:\.\d+)?)\s*ms')
_STATS_RE = re.compile(r'(\d+)\s+packets?\s+transmitted[,\s]+(\d+)\s+(?:packets?\s+)?received')
_LOSS_RE  = re.compile(r'(\d+(?:\.\d+)?)\s*%\s*packet\s+loss')
_RTT_SUM  = re.compile(r'rtt\s+min/avg/max(?:/mdev)?\s*=\s*(\d+(?:\.\d+)?)/(\d+(?:\.\d+)?)/(\d+(?:\.\d+)?)')

def parse_ping(text: str) -> Dict[str, Any]:
    tx = rx = loss = rmin = ravg = rmax = None
    times = []
    for line in text.splitlines():
        m = _RTT_RE.search(line)
        if m: times.append(float(m.group(1)))
        m = _STATS_RE.search(line)
        if m: tx, rx = int(m.group(1)), int(m.group(2))
        m = _LOSS_RE.search(line)
        if m: loss = float(m.group(1))
        m = _RTT_SUM.search(line)
        if m: rmin, ravg, rmax = float(m.group(1)), float(m.group(2)), float(m.group(3))
    if ravg is None and times:
        ravg = round(sum(times)/len(times), 3)
        rmin, rmax = min(times), max(times)
    return {"transmitted":tx,"received":rx,"loss_pct":loss,
            "rtt_min_ms":rmin,"rtt_avg_ms":ravg,"rtt_max_ms":rmax}
Time: O(n) where n = lines    Space: O(n)
What to say: "Compile regex at module level. Three separate patterns for maintainability. Graceful fallback: if RTT summary line is missing (complete loss), compute avg from individual times if present. Return None for truly missing values — don't return 0 (which could be a valid RTT)."

Parse Traceroute → First Lossy Hop

Medium

Given traceroute output, find the first hop where packet loss exceeds a given threshold percentage.

If hop 2 shows only 1 of 3 probes (66% loss) and threshold=30, return: {"hop": 2, "host": "10.0.0.2", "rtts_ms": [12.3], "loss_pct": 66.7}
Clarify First
  • What probe count does traceroute use? (default 3)
  • Is * * * definitely loss or possibly a firewall?
  • Return hop number only, or full dict?
  • Threshold inclusive or exclusive?
💡 Hint
Parse each line for hop number and RTT values. Count responded probes vs expected (3). Loss % = (1 - responded/3) × 100.
✅ Solution + Complexity 
import re
from typing import List, Dict, Any, Optional

HOP_RE = re.compile(r'^\s*(\d+)\s+(\S+)', re.MULTILINE)
RTT_RE = re.compile(r'(\d+(?:\.\d+)?)\s*ms')

def parse_traceroute(text: str) -> List[Dict[str, Any]]:
    hops = []
    for m in HOP_RE.finditer(text):
        line    = text[m.start():text.find('\n', m.start())]
        hop_num = int(m.group(1))
        host    = m.group(2)
        rtts    = [float(v) for v in RTT_RE.findall(line)]
        hops.append({
            'hop': hop_num,
            'host': None if host == '*' else host,
            'rtts_ms': rtts,
            'avg_rtt_ms': round(sum(rtts)/len(rtts), 2) if rtts else None,
        })
    return hops

def first_lossy_hop(text: str, threshold_pct: float = 30.0) -> Optional[Dict]:
    probes = 3  # traceroute default
    for hop in parse_traceroute(text):
        loss = (1 - len(hop['rtts_ms']) / probes) * 100
        if loss > threshold_pct:
            return {**hop, 'loss_pct': round(loss, 1)}
    return None
Time: O(n)    Space: O(n)
What to say: "Key insight: traceroute sends 3 probes per hop. If you see fewer RTT values than 3, that's implied loss. A hop showing * * * might just be a firewall blocking ICMP — mention this distinction. Correlate with the next hop to distinguish true loss from ICMP filtering."

✅ Solution + Complexity 
import re
from typing import List, Dict

_NEIGHBOR_RE = re.compile(
    r'^(?P<neighbor>\d{1,3}(?:\.\d{1,3}){3})'
    r'\s+\d+'              # version
    r'\s+(?P<asn>\d+)'     # AS
    r'(?:\s+\S+){4}'       # MsgRcvd MsgSent TblVer InQ
    r'\s+\S+'              # OutQ
    r'\s+(?P<updown>\S+)'  # Up/Down
    r'\s+(?P<state>\S+)',  # State/PfxRcd
    re.MULTILINE
)

def parse_bgp_summary(text: str) -> List[Dict]:
    results = []
    for m in _NEIGHBOR_RE.finditer(text):
        state = m.group('state')
        established = state.isdigit()
        results.append({
            'neighbor':    m.group('neighbor'),
            'asn':         int(m.group('asn')),
            'state':       'Established' if established else state,
            'prefix_count': int(state) if established else None,
            'established': established,
        })
    return results

def non_established_neighbors(text: str) -> List[str]:
    return [n['neighbor'] for n in parse_bgp_summary(text) if not n['established']]

def check_compliance(
    running_config: str,
    required_stanzas: List[str],
    case_sensitive: bool = False

    config = running_config if case_sensitive else running_config.lower()

from typing import List, Optional

def ipv4_to_int(ip: str) -> int:
    r = 0
    for p in ip.split('.'): r = (r << 8) | int(p)
    return r

def longest_prefix_match(ip: str, cidrs: List[str]) -> Optional[str]:
    ip_int = ipv4_to_int(ip)
    best, best_len = None, -1
    for cidr in cidrs:
        ip_str, plen_str = cidr.split('/')
        plen = int(plen_str)
        mask = (0xFFFFFFFF << (32 - plen)) & 0xFFFFFFFF if plen > 0 else 0
        net  = ipv4_to_int(ip_str) & mask
        if (ip_int & mask) == net and plen > best_len:
            best, best_len = cidr, plen
    return best

import subprocess, re, json
from typing import List, Dict, Any

def parse_bgp_established(bgp_text: str) -> Dict[str, bool]:
    """Return {neighbor_ip: is_established}"""
    result = {}
    pattern = re.compile(
        r'^(\d{1,3}(?:\.\d{1,3}){3})\s+\d+\s+\d+'
        r'(?:\s+\S+){4}\s+\S+\s+(\S+)',
        re.MULTILINE
    )
    for m in pattern.finditer(bgp_text):
        result[m.group(1)] = m.group(2).isdigit()
    return result

def check_ping(host: str, count: int = 3) -> Dict[str, Any]:
    """Run ping, return {host, reachable, loss_pct, avg_rtt_ms}"""
    try:
        res = subprocess.run(
            ['ping', '-c', str(count), host],
            capture_output=True, text=True, timeout=15
        )
        loss_m = re.search(r'(\d+(?:\.\d+)?)\s*%\s*packet\s+loss', res.stdout)
        rtt_m  = re.search(r'min/avg/max(?:/mdev)?\s*=\s*[\d.]+/([\d.]+)/', res.stdout)
        loss   = float(loss_m.group(1)) if loss_m else 100.0
        rtt    = float(rtt_m.group(1))  if rtt_m  else None
        return {'host': host, 'reachable': loss < 100, 'loss_pct': loss, 'avg_rtt_ms': rtt}
    except subprocess.TimeoutExpired:
        return {'host': host, 'reachable': False, 'loss_pct': 100.0, 'avg_rtt_ms': None}

def validate_deployment(
    bgp_summary_text: str,
    expected_neighbors: List[str],
    test_hosts: List[str]
) -> Dict[str, Any]:
    report = {
        'bgp': {'expected': expected_neighbors, 'down': [], 'up': []},
        'connectivity': [],
        'overall_pass': True,
    }
    # BGP check
    states = parse_bgp_established(bgp_summary_text)
    for neighbor in expected_neighbors:
        if states.get(neighbor, False):
            report['bgp']['up'].append(neighbor)
        else:
            report['bgp']['down'].append(neighbor)
            report['overall_pass'] = False

    # Connectivity check
    for host in test_hosts:
        result = check_ping(host)
        report['connectivity'].append(result)
        if not result['reachable']:
            report['overall_pass'] = False

    return report
