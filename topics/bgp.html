Message types

TypePurposeKey contents
OPENInitiate session; negotiate parametersBGP version, ASN, hold-time, BGP identifier (RID), optional params
KEEPALIVEConfirm session alive; ACK for OPENNo data — header only. Sent every 60 sec.
UPDATEAdvertise or withdraw routesWithdrawn routes, path attributes (AS-Path, Next-Hop, etc.), NLRI (prefixes)
NOTIFICATIONSignal error; tears down sessionError code + subcode + data. Session closes immediately after.

Key commands

CommandWhat it shows
show ip bgp summaryAll peers: state, uptime, AS, prefixes received. Stuck peers show FSM state instead of uptime.
show ip bgp neighbors [ip]Detailed peer info: state, timers, message counts, capabilities, hold-time negotiated.
show ip bgpFull BGP table: status codes (* valid, > best), next-hop, attributes.
show ip bgp [prefix]All paths for a specific prefix with full attribute detail — use for best-path debugging.
show ip route bgpOnly BGP routes installed in the routing table.
show ip bgp dampened-pathsRoutes currently suppressed by dampening.
clear ip bgp * softSoft reset: re-advertise/re-process routes without tearing down TCP session.
clear ip bgp *Hard reset: tears down all BGP sessions. Avoid in production.
debug ip bgp [ip] eventsReal-time FSM transitions for a specific peer.

Abbreviations

AbbreviationFull formBrief meaning
BGPBorder Gateway ProtocolThe routing protocol of the internet; connects autonomous systems
EGPExterior Gateway ProtocolProtocol class for routing between ASes (BGP is the only active EGP)
IGPInterior Gateway ProtocolProtocol for routing within an AS (OSPF, EIGRP, IS-IS)
ASAutonomous SystemCollection of IP prefixes under a single administrative policy
ASNAutonomous System NumberUnique identifier for an AS; used in AS-Path
eBGPExternal BGPBGP session between routers in different ASes
iBGPInternal BGPBGP session between routers in the same AS
RIBRouting Information BaseBGP's internal table of all received routes (before best-path selection)
NLRINetwork Layer Reachability InformationThe prefix(es) carried in a BGP UPDATE message
FSMFinite State MachineThe state machine BGP uses to track session establishment
MEDMulti-Exit DiscriminatorOptional attribute hinting to an external AS which entry point to prefer
RRRoute ReflectoriBGP router that re-advertises routes to clients, replacing full mesh
ADAdministrative DistanceTrustworthiness of a route source; lower = more trusted
TTLTime to LiveIP field; eBGP defaults to 1 (direct only); iBGP uses 255
TCPTransmission Control ProtocolTransport BGP runs over; provides reliable ordered delivery
MD5Message Digest 5Hash algorithm used for BGP neighbor authentication
