IPv4 vs IPv6 — quick facts

Address length
IPv4: 32-bit · IPv6: 128-bit
Address space
IPv4: ~4.29B · IPv6: 340 undecillion
Header size
IPv4: variable · IPv6: fixed 40 bytes
Checksum
IPv4: yes · IPv6: removed
Fragmentation
IPv4: routers fragment · IPv6: source only (Path MTU Discovery)
ARP
IPv4: ARP broadcast · IPv6: NDP (Neighbor Discovery, multicast)
Broadcast
IPv4: yes · IPv6: no (replaced by multicast)
EtherType
IPv4: 0x0800 · IPv6: 0x86DD
TTL equivalent
IPv6 uses "Hop Limit" (same function)
Security
IPv6 has built-in IPSec support
Auto-config
IPv6 supports SLAAC (no DHCP needed)
First RFC
IPv6 defined in RFC 1883, draft standard Dec 1998

SLAAC process (5 steps)

Step 1: Generating a link-local address from MAC using EUI-64
StepWhat happens
1Node generates link-local address: FE80::/64 + EUI-64 from MAC
2DAD — sends NS to solicited-node multicast of own address; if no reply, address is unique
3Node sends RS to FF02::2; router responds with RA containing prefix + prefix length
4Node combines prefix (from RA) + EUI-64 → global unicast address; sets default GW to router's LLA
5DAD again on the new GUA to confirm uniqueness

RA flags (M, O, A)

FlagNameWhen set to 1
AAddress AutoconfigurationHosts can use SLAAC for GUA. Default = 1.
OOther ConfigurationHosts use Stateless DHCPv6 for DNS/domain only; SLAAC handles addresses
MManaged Address ConfigurationHosts use Stateful DHCPv6 for addresses + DNS. A-flag typically set to 0.
